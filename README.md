# FAAPS Frontend

React, TypeScript, Vite, and Tailwind CSS frontend for FAAPS.

## Local development

```powershell
pnpm install
pnpm dev
```

Open `http://localhost:5173`. The `/api` path is proxied to the Spring Boot backend on port 8080.

The current frontend is a stack scaffold. FAAPS screens and Google sign-in are not implemented yet.
