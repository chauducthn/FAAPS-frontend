CÁCH CHỐT API CONTRACT
API contract là thỏa thuận FE và BE về cách một màn hình gọi dữ liệu. Chốt contract trước khi hai bên code song song để tránh
FE tự đoán tên trường, BE trả cấu trúc khác và phải sửa lại cả hai.
Ví dụ: danh sách tài khoản Admin
GET /api/admin/users?role=STUDENT&status=ACTIVE&search=SE173019&page=0&size=20&sort=userId,asc
Quyền: ADMIN. Trả về: items [{id, userId, fullName, email, avatarUrl, role, status}], page, size, totalElements, totalPages. Lỗi:
401 chưa đăng nhập; 403 không phải Admin; 400 bộ lọc/sort không hợp lệ.
Quy tắc UI: FE gửi role của tab đang chọn, chỉ hiển thị dữ liệu từ API; không tự tính total. BE chuẩn hóa status
ACTIVE/SUSPENDED và trả phân trang ổn định.
Ví dụ: auto-assign hai bước
POST /api/admin/assignments/auto-assign/preview với {cohortId, advisorIds}. Trả số sinh viên chưa được phân công, số dự kiến
cho từng advisor và danh sách thay đổi. Không ghi DB.
POST /api/admin/assignments/auto-assign/confirm với cùng lựa chọn và mã preview/version. BE kiểm tra lại dữ liệu trong
transaction, chỉ phân công sinh viên còn chưa có advisor, trả số thành công/bỏ qua. FE hiển thị kết quả thực tế, không coi
preview là kết quả cuối.
Quy ước tối thiểu của cả nhóm
• ID dùng kiểu thống nhất; thời gian trả ISO 8601 kèm múi giờ; semester và month là hai khái niệm khác nhau.
• Mọi list API dùng page, size, sort và totalElements; search/filter xử lý trên server. FE có loading, empty và error state.
• Lỗi validation trả mã, message và fieldErrors; lỗi quyền trả 401/403; lỗi xung đột dữ liệu trả 409.
• Endpoint Admin bắt buộc kiểm tra quyền ở BE, không chỉ ẩn nút trên FE.
• Mỗi module hoàn thành khi gọi DB thật, có kiểm thử luồng chính và ít nhất một trường hợp lỗi/ràng buộc.

// ==========================================
// FAAPS Database Schema - DBML Format
// For dbdiagram.io ERD Generation
// 40 Tables across 11 Groups
//
// Conventions:
// - Primary keys are UUID (generated by DB or application)
// - Scores and GPA use the 10-point scale (0.00 - 10.00), numeric only, no letter grades
// - Academic results are imported from FAP, they are not managed here
// ==========================================

// ==========================================
// GROUP 1: CORE IDENTITY & ACCESS
// ==========================================

Table roles [group: "Core Identity & Access"] {
  id uuid [pk, default: `(UUID())`]
  code varchar(50) [unique, not null, note: 'ADMIN, ADVISOR, STUDENT']
  name varchar(100) [not null]
  description text
  created_at timestamp [default: `CURRENT_TIMESTAMP`]
  updated_at timestamp [default: `CURRENT_TIMESTAMP`]
}

Table users [group: "Core Identity & Access"] {
  id uuid [pk, default: `(UUID())`]
  role_id uuid [not null, ref: > roles.id]
  email varchar(255) [unique, not null]
  password_hash varchar(255) [note: 'NULL when the account only signs in through an external provider (e.g. Google)']
  auth_provider varchar(20) [default: 'LOCAL', note: 'LOCAL, GOOGLE']
  external_id varchar(255) [note: 'Provider user id (Google "sub" claim)']
  full_name varchar(255) [not null]
  phone varchar(20)
  avatar_url varchar(500)
  status varchar(20) [default: 'ACTIVE', note: 'ACTIVE, INACTIVE, SUSPENDED, LOCKED']
  email_verified_at timestamp
  last_login_at timestamp
  failed_login_attempts int [default: 0]
  locked_until timestamp
  created_at timestamp [default: `CURRENT_TIMESTAMP`]
  updated_at timestamp [default: `CURRENT_TIMESTAMP`]

  indexes {
    (role_id, status)
    (auth_provider, external_id) [unique]
  }
}


Table refresh_tokens [group: "Core Identity & Access"] {
  id uuid [pk, default: `(UUID())`]
  user_id uuid [not null]
  token varchar(500) [unique, not null]
  expires_at timestamp [not null]
  revoked_at timestamp
  ip_address varchar(45)
  user_agent varchar(500)
  created_at timestamp [default: `CURRENT_TIMESTAMP`]

  indexes {
    (user_id, expires_at)
  }
}

Table password_reset_tokens [group: "Core Identity & Access"] {
  id uuid [pk, default: `(UUID())`]
  user_id uuid [not null]
  token varchar(255) [unique, not null]
  expires_at timestamp [not null]
  used_at timestamp
  ip_address varchar(45)
  created_at timestamp [default: `CURRENT_TIMESTAMP`]
}

  }

  is_mandatory boolean [default: true]
  created_at timestamp [default: `CURRENT_TIMESTAMP`]
  updated_at timestamp [default: `CURRENT_TIMESTAMP`]

  indexes {
    (curriculum_version_id, requirement_type)
  }
